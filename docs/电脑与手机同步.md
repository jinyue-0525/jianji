# 简记 2.0.0：电脑与手机同步

作者：@yue。笔记保存在各自设备上，无需账号；本版使用局域网同步，不使用云服务，也不包含蓝牙同步。

## 打开电脑版

- **Apple Silicon Mac**：使用 `简记-2.0.0-macOS-arm64.zip`。
- **Intel Mac**：使用 `简记-2.0.0-macOS-x64.zip`。
- **Windows x64**：完整解压 `简记-2.0.0-Windows-x64-portable.zip`，打开其中的 `Jianji.exe`。不要只复制 EXE，旁边的文件也需要保留。

Mac 解压后打开 `.app`，也可将它放进“应用程序”。当前 Mac 版本尚未经过 Apple 公证，Windows 版本尚未进行发行者签名；若系统拦截，请先确认程序来源。

## 第一次连接

1. 手机和电脑连接同一个 Wi-Fi，并打开两端简记。
2. 电脑版进入“设备同步”，选择当前 Wi-Fi 对应的本机地址，生成配对二维码。
3. 安卓版在首页更多菜单进入“电脑同步”，扫描二维码，并确认电脑名称。也可使用“粘贴配对码”。
4. 回到电脑，确认申请配对的手机并批准。二维码有效期为 5 分钟，过期后重新生成。
5. 配对成功后，在手机点“立即同步”，或在电脑向已配对手机发起同步。配对本身不会自动传输笔记。

同步期间保持电脑窗口打开、手机简记处于前台，不要锁屏或切到其他应用。电脑发出的请求需要手机前台响应；这是手动发起的双向同步，不是后台实时同步。暂时离线时仍可在本机写作，重新连接后再同步。

## 哪些内容会同步

- 两端的笔记正文、文件夹、笔记本、插入的图片，以及收藏、置顶和回收站状态。单张图片最多 30 MiB。
- 两端都修改过同一篇笔记时，会保留需要人工整理的冲突副本，正文不会被添加冲突标题。比较内容后再决定保留哪一份。
- 移入回收站和永久删除也会同步。一端删除、另一端同时编辑时，可能保留冲突副本；已删除的目录不会因旧记录重新出现，其仍保留的笔记会显示在“未分类”。
- 字体大小、界面布局和设备配对信息各自保存在本机，不随笔记同步。

看到“同步完成”再继续操作。中断或失败后可重新发起；如果提示本机内容已合并但电脑尚未确认，再同步一次完成确认即可。

## 连不上时

确认电脑端仍打开，选择的是当前 Wi-Fi 地址，并允许简记通过系统防火墙和本地网络权限。访客 Wi-Fi 或路由器的设备隔离设置可能阻止两台设备互相访问；可换到允许设备互通的私人网络。无需设置公网端口转发。

电脑 IP 或证书变化后，需要重新扫码配对。解除配对只停止后续连接，不删除两端已有笔记。

## 本地保存与备份

程序重开后会读取本机保存的数据。Windows 的“便携版”指程序无需安装，笔记仍保存在当前系统用户的数据目录；只复制程序文件夹不会带走笔记。

桌面数据目录包含笔记清单、图片和 `backups` 备份。手机数据保存在应用私有目录。同步导入前会保留合并前的清单，图片另行保存以供恢复；目前没有一键恢复入口。更换设备或卸载前，先完成同步，并另外保留重要内容；卸载安卓应用会删除本机应用数据。
